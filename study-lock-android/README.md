# 学习锁屏

当前版本 **0.5.0，无需无障碍版**。原生 Android 应用，目标 Android 16，最低 Android 13。每天 19:00–23:00，每小时学习 50 分钟、休息 10 分钟。无需 USB、Root、电脑配置或设备所有者身份。

## 手机内三步开始

1. 点击“完成手机授权”，按系统提示允许悬浮窗、使用情况访问、电话状态、通知和闹钟。系统名称可能显示为“显示在其他应用上层”“查看应用使用情况”。**不需要打开任何无障碍服务。**
2. 保存急救码备份。已有长码继续有效；妻子不在时可先准备封存纸条。
3. 点击“验证并开始学习”。先校验本机急救存储，再启用每日计划。妻子端验证可稍后完成。

学习时保留一条低打扰运行通知，休息开始与结束另有闹钟提醒。允许本应用自启动和后台运行，减少厂商省电清理。完整试运行在“更多与帮助”，不再作为强制开通步骤。

## 本版移除了什么

生产 APK 不声明 `BIND_ACCESSIBILITY_SERVICE`，不注册无障碍服务，不包含旧无障碍服务类和元数据。旧安装覆盖升级后，已移除的组件不再运行。保留旧版设备管理员接收器仅用于已经配置过设备所有者的用户退出旧管理身份，新用户无需启用。

屏幕遮罩改用 `TYPE_APPLICATION_OVERLAY`；前台服务声明 `specialUse`，只在当前学习窗口或试运行期间运行。19:00 等边界由用户设置的本地精确闹钟启动，休息期间维持切换，结束后移除遮罩并停止运行通知。

“使用情况访问”用于取得 Activity 的包名、界面类名及前后台事件，以区分通话页和聊天页。不读取屏幕文字、聊天内容、号码或联系人，不代点。启动时可查询最近系统活动元数据以确定当前页面，之后只增量处理；不持久记录或上传应用使用历史。无联网权限、账号、广告、分析 SDK 或第三方运行依赖。

## 时间、息屏与电话

| 学习遮罩 | 休息 |
| --- | --- |
| 19:00–19:50 | 19:50–20:00 |
| 20:00–20:50 | 20:50–21:00 |
| 21:00–21:50 | 21:50–22:00 |
| 22:00–22:50 | 22:50 起休息，23:00 后继续自由使用 |

点击应用图标、息屏、亮屏和服务重连不重置原到期时间。系统锁屏优先；解锁后按当前学习或休息段恢复。计时使用本地时间和单调时钟后手，不需要网络或 AI 在线。

默认电话界面与系统来电提示保持可用，返回桌面或其他应用后仍显示遮罩。不再因为“正在通话”就解锁整部手机。电话状态权限只判断是否来电或通话，不读取号码、联系人、通话记录，不自动拨号。

微信仅匹配独立语音、视频通话页：

`com.tencent.mm / com.tencent.mm.plugin.voip.ui.VideoActivity`

该页面已从 [微信官网](https://weixin.qq.com/) 指向的腾讯官方 Android 8.0.79 安装包清单核对。普通聊天页面、联系人、桌面没有例外。本应用不主动启动微信。元数据轮询存在检测延迟；未知页面继续遮挡，不按“voip”或“video”字样模糊放行。

实际微信来电、微信小窗、群聊及不同厂商弹窗仍需实机验证。CI 中的模拟通话界面不是微信，也不代表已登录真实账号完成通话。系统设置、通知栏、系统手势和卸载入口不可能由普通应用完全禁止；返回桌面时应由遮罩覆盖，不能承诺禁止 Home 手势。强行停止、撤销权限、修改时间或厂商后台清理仍可能绕过限制。

## 长码保持不变，急救当晚解除

64 位随机长码只在设置时显示，可一键复制交给妻子或封存到纸上。不按天更换；未实际急救使用前，不提供重新生成入口。实际用过后可主动更换；完成新码保存前旧码继续有效。不要把长码上传 GitHub，清理自己聊天与其他可找回的副本。

急救入口显示 12 位临时挑战号和本应用数字键盘。妻子在已保存的 `recovery-helper.html` 输入长码和挑战号，算出 8 位一次性码，通过普通电话口述。挑战号不是妻子保存的长码，15 分钟有效，成功使用后消耗，重启后失效。5 次错误短码暂停验证 60 秒。

成功后当晚不再限制，已启用的每日计划次日 19:00 恢复。完全失联时可输入封存纸质长码，或等休息。网页不联网、不上传、不保存输入；必须稍后在妻子手机上验证本地 HTML 能运行，本机自检不能代替实际托管验收。

应用 ID、固定签名、SharedPreferences 名称、Keystore 别名、长码加密与哈希、挑战应答协议均保留。0.2.0–0.4.0 可覆盖安装保留长码；旧计划在新权限未齐时保留计时但不声称已经拦截，完成新授权后继续。不要先卸载旧版，否则会丢失本机数据。0.1.0 的临时签名包不能覆盖，需在非学习时段先移除旧管理身份再换装，不要恢复出厂设置。

## 验证

- JVM：日程边界、时钟与重启、HMAC、长码替换、电话/微信通话与聊天/桌面规则、Activity 元数据的乱序与重放。
- Node：离线网页 SHA-256、HMAC、200 个独立应答、分组及输入校验。
- GitHub 云端 Android 16：保持无障碍总开关关闭，验证真实 Keystore、正常前台服务、真实悬浮窗、图标重开、息屏亮屏、默认拨号页、后台精确闹钟启动、休息与最终退出，以及长码不变。
- `call-fixture/` 是仅供 CI 安装的独立模拟应用，以相同包名和类名生成真实 UsageEvents，检查通话页让行、切到聊天和桌面重新遮挡。它不是微信，不联网，不登录账号，不上传给用户，也不打入学习锁屏 APK。
- 仍需在用户小米 14 / HyperOS 上验证后台权限、真实电话接听、微信语音与视频来电，以及妻子手机的离线网页。

先用“更多 → 两分钟检测”检查本机表现。有异常可从系统设置撤销权限；界面中显示“计时保留”不等于其他应用仍被拦截。

## 云端构建与下载

工程在 `study-lock-android/`，工作流在根目录 `.github/workflows/build.yml`。Java 17、Gradle 8.13、Android SDK 36。云端同时运行原生模拟器检查和非调试 APK 构建，用户电脑无需安装模拟器或 Android Studio。

**StudyLock-Android16-APK** 仅含 `study-lock.apk`、`recovery-helper.html`、`SHA256SUMS`。固定签名私钥只在 GitHub 加密 Secret，不进仓库、测试模拟器或产物。**StudyLock-Android16-Lifecycle-Evidence** 单独保存测试日志。Actions 产物需登录 GitHub，保留 3 天；本地保存的文件不受期限影响。

本次没有提交应用商店；上架时需另行申报前台服务用途等材料，不能承诺审核结果。备用本地构建运行 `./build.ps1`，需 JDK 17、SDK 36、build-tools 36.0.0，输出 `dist/学习锁屏-0.5.0.apk`。

系统机制：[普通悬浮窗](https://developer.android.com/reference/android/view/WindowManager.LayoutParams#TYPE_APPLICATION_OVERLAY)、[UsageEvents](https://developer.android.com/reference/android/app/usage/UsageEvents.Event)、[特殊用途前台服务](https://developer.android.com/develop/background-work/services/fgs/service-types#special-use)、[用户设置的精确闹钟与后台启动](https://developer.android.com/develop/background-work/services/fgs/restrictions-bg-start)。
