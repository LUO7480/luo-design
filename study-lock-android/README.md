# 学习锁屏

原生 Android 应用，当前版本 **0.3.0 免 USB 大众版**。支持 Android 13 及以上，目标 Android 16。安装 APK 后只在手机内授权；不需要电脑、USB 调试、Root 或设备所有者配置。

每日本地时间 19:00–23:00：普通应用与桌面上显示专注遮罩，每小时最后 10 分钟自动移除，整点重新显示。电话、系统设置、撤销授权和卸载入口保持可用。本应用是自愿使用的自律工具，不能禁止全部系统手势，也不能防止主动关闭权限、强行停止、修改时间或卸载。

## 安装与首次使用

1. 安装下载包中的 `study-lock.apk`。安装本身不会启用计划。
2. 打开应用，阅读并同意无障碍用途说明，在系统无障碍页面开启“学习锁屏 · 专注遮罩”。
3. 允许电话状态权限、闹钟和提醒、休息通知。电话权限仅用于判断是否来电或通话，不读取号码、联系人或通话记录。
4. 按本机系统设置，允许自启动、后台运行，并减少对本应用的省电限制。不同品牌入口不同，应用提供说明和应用详情入口。
5. 把随机急救码交给妻子，保存离线工具并验证，再完成两分钟试运行。
6. 勾选实际验收结果，启用每日计划。

若无障碍开关变灰，Android 13 及以上系统可能需要先进入“设置 → 应用 → 学习锁屏 → 右上角更多 → 允许受限设置”。确认安装包来源可信后再授权。小米等系统名称和位置可能不同，以本机提示为准。详见 [Android 受限设置说明](https://support.google.com/android/answer/12623953)。

无障碍服务使用窗口切换事件中的应用包名，不请求读取窗口内容，不执行手势或代点。遮罩使用 `TYPE_ACCESSIBILITY_OVERLAY`，无需另外授权“显示在其他应用上层”。授权开启但服务尚未连接时，首页明确显示当前无法限制其他应用；未连接前不能开始试运行。

## 时间与电话规则

| 专注遮罩 | 自由使用手机 |
| --- | --- |
| 19:00–19:50 | 19:50–20:00 |
| 20:00–20:50 | 20:50–21:00 |
| 21:00–21:50 | 21:50–22:00 |
| 22:00–22:50 | 22:50 起休息，23:00 后继续自由使用 |

由本地闹钟切换，无需网络、路由器或 AI。休息开始与结束通过通知渠道播放闹钟声音。手机本身需有电；通知渠道、闹钟音量、勿扰设置与厂商后台管理都可能影响提醒。

来电、拨号、通话和保留通话期间，**暂时移除遮罩，允许使用手机**，避免遮挡不同厂商的接听界面。挂断后恢复当前学习段。这个设计允许通话时使用其他应用，不能靠本版阻止刻意用通话绕过学习。系统自带锁屏、紧急呼叫及授权页面优先于学习遮罩。

应用内在当晚学习及休息期间不能修改当天计划或重新托管码；系统设置仍可以撤销权限或卸载。重启后需先解锁手机，无障碍服务重连后才会恢复有效计划。系统关闭服务或强行停止时不能保证拦截；不会宣称手机仍被锁住。

## 妻子保管长码，手机输入短码

1. 点击“先把急救码交给妻子”。本机随机生成 **64 位数字长码**，每 4 位一组，可一键复制，仅在本次设置时显示。
2. 妻子把长码保存到离线密码库或纸上，同时保存下载包中的 `recovery-helper.html`。务必先确认她的手机浏览器能打开本地 HTML 并在飞行模式下计算短码；不同文件管理器、浏览器可能限制本地网页运行。
3. 完成托管会清除仍属于本应用的长码剪贴板。自行清理聊天里的发送记录和其他备份，避免在休息时找回。应用不能阻止主动抄录或保存长码。
4. 需要急救时，点击遮罩或学习界面的“离线急救解锁”。本机显示 **12 位挑战号**和应用自己的数字键盘，不依赖微信或系统输入法。
5. 通过普通电话把挑战号告诉妻子。她在离线网页输入长码和挑战号，得到 **8 位一次性码**，口述给你。
6. 输入短码后当晚不再限制；已启用的每日计划次日 19:00 恢复。

挑战号有效 15 分钟，成功后消耗，重启后失效。不依赖妻子手机的时钟。连续输错 5 次后短码暂停验证 60 秒；关闭对话框不能清除计数。

本机用 Android Keystore AES 密钥加密长码，另存长码哈希用于纸质备份。离线网页使用 HMAC-SHA256 挑战应答，不联网、不上传、不持久保存输入，也不含外部脚本。真实急救码在每部手机上独立生成，不在源码、聊天或 APK 中预置。

若妻子也无法通话，需预先封存一份可以取得的 **64 位纸质长码**。点击“改用纸质长码”后在本机数字键盘分组输入。即使本机密钥库暂不可用，纸质长码仍可通过已存哈希验证。不留可取得的备份，就只能等下个休息时段、23:00 或在系统设置撤销权限。

首页“验证急救码（不改变计划）”用于先验证妻子的离线工具，不跳过当晚学习。试运行中使用急救码会结束试运行，之后必须重新完整试运行。

## 旧版升级与回退

- **0.2.0 → 0.3.0**：应用 ID 和签名保持一致，可覆盖安装，保留急救码、Keystore 别名、原有设置及离线网页协议。新版验证标记变化，旧每日计划会停止，必须重新授权与试锁。
- 曾配置设备所有者的旧安装：新版首先恢复本应用先前保存的系统策略；首页提供“旧版升级：移除原设备管理身份”。该操作由用户点击确认，不清空手机，不删除急救码。新用户不会看到此入口。
- **0.1.0 云端包**使用临时调试签名，不能直接覆盖。需先在非学习时段移除旧管理身份并卸载，再安装新版并重新托管。不要为换版恢复出厂设置。
- 出现升级问题先在系统设置关闭新版无障碍服务，停用计划；数据仍保留。Android 通常不允许直接安装更低版本号。若需要恢复旧版，应使用同签名、更高版本号的兼容修复包，不能通过卸载来假称保留数据。
- `recovery-helper.html` 与 0.2.0 协议相同；原有妻子端工具可继续使用。

## 验收后再正式启用

两分钟试运行：锁 60 秒、休息 30 秒、再锁 30 秒，之后恢复。

1. 切到桌面和普通应用，确认出现遮罩，无法点击底层应用；系统设置仍可打开。
2. 用另一部电话测试接听、拨打、挂断，以及挂断后恢复遮罩。不要实际拨打紧急号码。
3. 检查休息开始时自动恢复、提醒声音、休息结束自动锁回、最终自动退出。
4. 检查急救挑战号、原生数字键盘及妻子离线工具。先做不改变计划的验证。
5. 再验证关屏后解锁、重启后首次解锁、跨过 19:00、23:00，以及厂商省电状态。

有一项失败，就保持每日计划关闭。新版本、系统或默认拨号应用变化后要求重新试锁。自动化测试和编译不能证明每个品牌的来电、后台和权限表现，仍需实机验收。

## 隐私与分发

无广告、账号、联网权限或第三方运行依赖。不读取屏幕文字、联系人、号码或通话记录。仅在本机使用应用包名、通话状态、定时计划和急救验证数据；不记录前台应用历史。卸载会移除应用数据，妻子保存的长码与文件由她自行处理。

APK 可直接分发给自愿安装的用户。各手机的安全扫描、受限设置和后台限制可能增加安装步骤，不能承诺所有手机点一次即可启用。上架应用商店需另行准备商店材料和申报；本次没有提交或获得商店审核。Google Play 对非辅助功能用途的无障碍 API 要求显著披露、用户同意及相应声明；本应用设置 `isAccessibilityTool=false`，不伪称残障辅助工具。详见 [无障碍服务政策](https://support.google.com/googleplay/android-developer/answer/10964491)。

## GitHub 云端编译

仓库工程在 `study-lock-android/`，工作流在根目录 `.github/workflows/build.yml`。提交源码自动触发，也可在 **Actions → Build Android APK → Run workflow** 手动启动。个人电脑无需安装 Android Studio 或模拟器。

工作流使用 Java 17、Gradle 8.13、Android SDK 36：验证日程、急救、遮罩判断和离线网页，再构建非调试 APK，以已有固定签名密钥签名。私钥保存在 GitHub Actions 加密 Secret，不提交到仓库或产物。后续必须保留同一签名密钥才能覆盖升级。

从最新成功运行的 **Artifacts → StudyLock-Android16-APK** 下载 ZIP，内含 `study-lock.apk`、`recovery-helper.html`、`SHA256SUMS`。Actions 产物需登录 GitHub，保留 3 天；本地保存的文件不受此期限影响。该链接适合构建验收，不是永久公开分发链接。

不预设编译耗时或 APK 大小，以本次结果为准。云端构建和原生代码本身不会提高系统权限或保证更省电。仓库额度说明见 [GitHub Actions 计费文档](https://docs.github.com/en/billing/concepts/product-billing/github-actions)。

备用本地构建：准备 JDK 17、Android SDK 36 和 build-tools 36.0.0，运行 `./build.ps1`；可使用 `-JdkPath` 与 `-SdkPath` 指定工具。输出 `dist/学习锁屏-0.3.0.apk`。本机签名密钥在忽略提交的 `.tools/studylock.keystore`，不可提交或公开。

系统能力依据：[无障碍服务](https://developer.android.com/reference/android/accessibilityservice/AccessibilityService)、[通话状态](https://developer.android.com/reference/android/telecom/TelecomManager#isInCall())、[本地精确闹钟](https://developer.android.com/develop/background-work/services/alarms)。
