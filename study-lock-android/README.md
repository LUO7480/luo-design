# 学习锁屏

给小米 14 / Android 16 准备的原生 Android 应用。当前版本 0.2.0：每天本地时间 19:00–23:00，每小时锁 50 分钟、休息 10 分钟；保留电话和离线急救数字键盘。所有计时、提醒触发和急救验证均在本地完成，不需要路由器、互联网或 AI 在线。

已通过本地编译、签名、日程与到期逻辑、HMAC 跨端计算测试。尚未在用户的小米 14 上验证系统手势、电话、提醒声音及密钥库行为，正式启用前必须完成应用中的 2 分钟试运行。

## 休息规则

| 限制屏幕操作 | 自由使用手机 |
| --- | --- |
| 19:00–19:50 | 19:50–20:00 |
| 20:00–20:50 | 20:50–21:00 |
| 21:00–21:50 | 21:50–22:00 |
| 22:00–22:50 | 22:50 起休息，23:00 后继续自由使用 |

休息开始和结束通过本地闹钟自动切换，发出通知渠道配置的闹钟声音。手机本身需有电。通知权限、闹钟音量、勿扰设置及厂商后台限制都可能影响提醒声音，需实机验证。

休息期间可使用手机；当天计划、急救码托管和设备管理身份在 19:00–23:00 内仍不可通过本应用关闭或修改。日期时间设置限制也保持到 23:00，防止在休息段修改时间来跳过学习。

## 妻子保管长码，锁屏输入短码

1. 在应用点击“先把急救码交给妻子”。本机随机生成 **64 位数字长码**，每 4 位一组，可一键复制，只在本次设置时显示。
2. 把长码交给妻子。妻子保存到离线密码库或纸上，并保存下载包中的 `recovery-helper.html`。确认她能离线读取后完成托管。
3. 清理自己聊天中含长码的发送记录，避免在休息期间找回。完成托管时应用会清除仍属于本应用的长码剪贴板；不会删除其他应用中保存的消息或备份。
4. 需要急救时，点击锁屏中的“离线急救解锁”。锁屏内一直可见 **12 位挑战号**和本应用自己的数字键盘，不依赖微信、系统输入法或剪贴板。
5. 通过普通电话把挑战号告诉妻子。妻子用浏览器打开已保存的离线网页，输入长码和挑战号，得到 **8 位一次性码**，口述给你。
6. 在锁屏数字键盘输入这 8 位数字，立即解除当晚限制；已启用的每日计划次日 19:00 自动恢复。

短码和本次挑战号绑定，挑战号 15 分钟有效，成功后消耗，重启后失效。不依赖妻子手机的时间。连续输错 5 次后，短码暂停验证 60 秒；关闭弹窗不能清除计数。保管码与程序签名密钥不是同一件事；真实保管码只在手机上生成，不在 GitHub 源码或 APK 中预置。

本机用 Android Keystore 中的 AES 密钥加密保管码，另存长码哈希用于纸质备份验证。网页使用 HMAC-SHA256 挑战应答，不联网、不上传、不持久保存输入，不含外部脚本。长码应由妻子单独保存，不能只留在一条需要联网才能查看的消息中。

### 两人完全失联时

若妻子也无法通话，短码口述不可用。必须提前准备一份封存、在需要时可以取得的 **64 位纸质长码**。锁屏内点击“改用纸质长码”，按每组 4 位输入即可；无需查看微信或复制粘贴。即使本机密钥库暂不可用，纸质长码仍可通过已存哈希验证。

不留任何自己可取得的备份，就无法保证完全失联时随时提前解锁，只能等休息或 23:00。这与“完全不能自行解除”无法同时保证。长码能降低无意记住的可能性，不能阻止主动记录、保存发送记录或提前拆封纸质备份。

正式启用前，可在首页使用“验证急救码（不改变计划）”验证妻子的离线工具。该验证不跳过当晚学习。试运行中使用急救码则立即结束试运行，需要重新完整试运行后才能启用每日计划。

## GitHub 云端编译

安卓工程位于仓库的 `study-lock-android/` 子目录，工作流位于仓库根目录的 `.github/workflows/build.yml`。源代码提交后自动运行，也可在仓库的 **Actions → Build Android APK → Run workflow** 手动启动。

首版 0.1.0 的历史构建记录见 [GitHub Actions](https://github.com/LUO7480/luo-design/actions/runs/39023827595)。最新版本请从仓库 Actions 中打开最新成功的 **Build Android APK** 运行下载。

云端使用标准 Ubuntu 运行器、Java 17、Gradle 8.13 和 Android SDK 36。先验证日程、急救与网页逻辑，再生成并验证原生 APK。个人电脑无需安装 Android Studio、模拟器或开发工具。

构建成功后，打开本次运行的 **Artifacts → StudyLock-Android16-APK**，下载 ZIP。`study-lock.apk` 安装到你的手机；`recovery-helper.html` 交给妻子保存到她的手机；`SHA256SUMS` 用于校验。下载需要登录有权限的 GitHub 账号。产物保留 3 天；保存到手机的文件不受这个期限影响。

私有仓库使用账号内含的免费分钟数和产物存储额度，超额可能收费或停止运行。此工作流使用单个标准 Linux 运行器，15 分钟超时，不启用构建缓存。不会修改账号账单或付费预算。详见 [GitHub Actions 额度说明](https://docs.github.com/en/billing/concepts/product-billing/github-actions)。

不保证首次构建在 2 分钟内结束，也不预设 APK 大小。体积以构建摘要为准。Java 与 Kotlin 均可生成原生 APK；本项目复用已有 Java 源码，不引入 WebView 或跨平台运行时。云端编译和“纯原生”本身不会提高 HyperOS 系统权限或保证更省电。

从 0.2.0 起，云端使用固定签名和非调试 release APK。签名私钥以 GitHub Actions 加密 Secret 保存，不提交到仓库或产物，后续保留同一密钥即可覆盖升级。**旧 0.1.0 云端包用了临时调试签名，不能直接覆盖；需先在非学习时段移除设备管理，再卸载后换装 0.2.0。** 不要在锁定过程中强行更换安装包。

**云端编译只解决打包和下载；完整禁止系统手势仍需要手机端的设备管理配置。** 下载 APK 后可在手机文件管理器中直接安装；下面的 ADB 安装命令是可选途径，设备管理配置则另行处理。

## 安装

云端安装包为 `study-lock.apk`；备用本地构建输出 `dist/学习锁屏-0.2.0.apk`。默认关闭每日计划，安装不会自动锁定手机。首次安装或重新安装后，需重新托管急救码。

此版本不是微信小程序，也不是透明触摸遮罩。阻止系统手势需要 Android 的设备所有者权限。普通设备管理员或无障碍授权不等同于设备所有者。

需要用户自行开启 USB 调试、通过 USB 连接电脑并在手机上允许本电脑调试。连接后先检查：

```powershell
.\.tools\sdk\platform-tools\adb.exe devices -l
```

确认选中的是本人手机后，可安装 APK。多个设备在线时必须添加 `-s 序列号`：

```powershell
.\.tools\sdk\platform-tools\adb.exe install -r '.\dist\学习锁屏-0.2.0.apk'
```

**以下命令会改变手机的设备管理身份，必须得到用户明确同意后再执行。** 它本身不会清空手机，但已有账户、其他管理员或厂商限制可能使配置失败。遇到失败应停止并查看原始错误；不要直接删除账户或恢复出厂设置。

```powershell
.\.tools\sdk\platform-tools\adb.exe shell dpm set-device-owner cn.studylock/.AdminReceiver
```

应用内允许“闹钟和提醒”，用于到点启动和解除。根据小米系统实际设置，可能还需允许自启动和后台弹出界面；这些项目的名称和是否需要必须实机确认。

## 验收后再启用

1. 托管急救码，验证妻子的离线网页，然后允许“闹钟和提醒”及通知权限。
2. 点击“先试运行 2 分钟”：锁 60 秒、休息 30 秒、再锁 30 秒，之后全部恢复。
3. 检查锁定段的手势限制、电话接听/拨打，以及急救数字键盘能否打开。
4. 检查电源菜单的紧急呼叫入口，无需实际拨打紧急号码。
5. 确认休息提醒、自动恢复、休息结束后锁回，以及电话界面在前台时也能到期恢复。
6. 全部通过后勾选确认项，再启用每日计划。

有任一项目失败，就保持每日计划关闭。系统版本或默认拨号应用变化后，应用要求重新试锁。还需实机验证关屏后解锁、重启后解锁、息屏跨过 19:00 和 23:00 的行为。

## 解除与卸载

不改变原有系统解锁密码。23:00 自动解除；急救码可提前解除当晚限制。不依赖聊天或在线服务保管、验证密码。

非学习时段可关闭每日锁定，或点击“移除设备管理”后正常卸载。该按钮不清空手机。休息段内这两项仍被禁用；急救成功后可正常处理。

如定时权限不可用、拨号界面无法打开或系统拒绝锁定，应用尝试撤销自身策略并关闭计划。定时切换不依赖学习画面持续在前台；锁定段同时保留单调时钟到期后手。重启后重建日程，试运行不因重启重新计时。上述路径仍需实机验证。

## 构建

无第三方运行依赖，无联网权限，不读取联系人、通话记录或屏幕内容。源码位于 `app/src/main/java/cn/studylock/`。支持 Android 13 及以上，目标 SDK 36。

云端编译无需在个人电脑安装工具。如需使用备用本地构建脚本，先准备 JDK 17 和 Android SDK 36，再运行：

```powershell
.\build.ps1
```

脚本先运行日程与到期测试，再编译、打包、对齐和签名 APK。签名为本地开发用途，密钥保存在忽略提交的 `.tools/studylock.keystore`。更新安装时保留同一密钥。

其他电脑可指定已安装的工具路径：

```powershell
.\build.ps1 -JdkPath 'C:\path\to\jdk-17' -SdkPath 'C:\path\to\Android\Sdk'
```

SDK 需含 `platforms/android-36` 和 `build-tools/36.0.0`。标准 Gradle 云端构建和备用 PowerShell 本地构建均已通过。

系统能力依据：[Android 锁定任务模式](https://developer.android.com/work/dpc/dedicated-devices/lock-task-mode)、[设备配置要求](https://developer.android.com/work/dpc/dedicated-devices)、[精确定时](https://developer.android.com/develop/background-work/services/alarms)。
