# 学习锁屏

原生 Android 应用，当前版本 **0.4.0 简化版**。Android 13 及以上可安装，目标 Android 16。不需要电脑、USB 调试、Root 或设备所有者配置。主流程只有：**完成授权 → 保存急救码备份 → 验证并开始学习**。

每日 19:00–23:00，每小时学习 50 分钟、休息 10 分钟。普通应用与桌面上显示遮罩；19:50、20:50、21:50 开始休息，整点恢复；22:50 起休息，23:00 后继续自由使用。

## 本次修正

- 打开应用图标时返回当前学习页面，不因为页面打开而结束计时。
- 服务断开不再取消试运行或每日计划；保留原到期时间，重连后继续。遮罩暂时创建失败会重试，界面明确显示当前无法拦截，不能宣称仍在锁定。
- 息屏不取消计划、不重新计时；无障碍服务监听亮屏、息屏和解锁事件。系统锁屏优先，解锁后按当前学习或休息段恢复。设备被厂商清理、强行停止或撤销权限时仍可能失效。
- 首页移除六步清单和强制检测确认框。点击开始时自动校验本机 Keystore、已存长码哈希及急救协议测试向量，不消耗急救码；妻子端验证可以稍后完成。
- 64 位保管长码长期有效，不按天更新。未实际急救使用前，不提供重新生成入口；实际使用后可主动更换，完成新码保存前旧码仍有效。
- 通话期间不再放行所有应用。默认电话界面可用；微信只匹配独立通话页面，聊天、桌面和其他应用仍被覆盖。切换应用不停止学习计时。

## 首次使用

1. 安装 APK，打开“完成手机授权”。同一个入口会按缺少的项目引导无障碍、电话状态、通知、闹钟和提醒。系统授权页仍需本人确认。
2. 点击“保存急救码备份”，将随机长码交给妻子或先写成封存纸质备份。长码只在这次设置时显示，可一键复制。保存后清理自己聊天与剪贴板里的副本，避免在休息时找回。
3. 点击“验证并开始学习”。通过本机校验后启用每日计划；当前在锁定段则立即开始，其他时间等下一学习段。

“更多与帮助”中保留可选两分钟检测、妻子端短码验证、后台设置说明及非学习时段关闭计划入口。测试阶段建议先用可选检测，不必等妻子在场。

部分 Android 13 及以上设备安装文件 APK 后，需要先在“应用详情 → 更多 → 允许受限设置”再打开无障碍。确认安装来源可信后再授权。可关闭无障碍快捷方式或悬浮小按钮以减少误触，但应保留服务总开关。厂商入口以本机为准。[Android 受限设置说明](https://support.google.com/android/answer/12623953)。

## 为什么仍要无障碍

本版用窗口切换事件中的应用包名和界面类名识别应遮住的页面，不读取窗口内容、屏幕文字、聊天或密码，不执行手势或代点。遮罩使用 `TYPE_ACCESSIBILITY_OVERLAY`，无需再开普通悬浮窗权限。

不用无障碍也可以重新设计为普通悬浮窗版，但还要处理悬浮窗授权、前台常驻服务、后台启动限制，以及识别微信通话页所需的使用情况访问等能力。这不会自动减少授权步骤。本次沿用已经授权的无障碍，简化用户界面并修复连续性。

用户可以在系统设置撤销权限、强行停止或卸载。系统手势、时间修改及厂商后台清理也可能绕过限制。本应用不能完全锁死手机，无法阻止用户进入所有系统界面。

## 普通电话与微信通话

默认拨号应用、系统电话和紧急呼叫界面保持可用。电话状态权限只用于检测真实通话状态并允许系统来电提示，不读取号码、联系人、通话记录，也不自动拨号。返回桌面或其他应用后仍显示学习遮罩，不因“正在通话”而解锁整部手机。

微信只在其主动展示已适配的独立通话页时让行。本应用不主动启动微信，不将整个微信包加入白名单。当前精确匹配：

`com.tencent.mm / com.tencent.mm.plugin.voip.ui.VideoActivity`

该独立页面已从腾讯官网下载的 **微信 Android 8.0.79** 安装包清单核对。下载地址来自 [微信官网](https://weixin.qq.com/)，对应 [腾讯安装包](https://dldir1v6.qq.com/weixin/android/weixin8079android3200_0x28004f30_arm64_1.apk)。清单验证能证明页面存在，**不能证明用户当前版本的来电、语音、视频及小米弹窗均已可接听**。

未知页面继续拦截，不因为名字包含“voip”或“video”就放行。微信聊天页、联系人页和桌面不获通话例外。系统设置仍保留。群聊通话、微信小窗及厂商自定义来电卡片未作保证；需要真实来电验证，不能把普通电话检测当成微信通话检测。

## 长码固定，临时挑战号可变化

64 位长码由每部手机独立随机生成，不在生产 APK 或仓库预置。长码保存在本机 Android Keystore AES 加密存储中，并有独立哈希供纸质备份验证。

急救时本机显示 **12 位临时挑战号**和原生数字键盘。这不是妻子保管的长码。妻子在预先保存的 `recovery-helper.html` 输入长码与本次挑战号，计算 **8 位一次性码**，可通过普通电话口述。无需在被限制的手机打开微信或复制粘贴。

挑战号 15 分钟有效，重启或成功使用后失效；连续 5 次错误短码暂停验证 60 秒。长码不按天更换；实际急救后只显示主动更换入口，不自动生成妻子未知的新长码。验证妻子端工具不会标记保管长码已实际使用。

急救成功后当晚解除，已启用的每日计划次日 19:00 恢复。完全失联时，可改用封存的 64 位纸质长码，或等下个休息时段。妻子端网页不联网、不上传、不持久保存输入；必须稍后在她手机上验证浏览器能打开本地 HTML，不能以本机算法自检代替真实托管验收。

## 验证范围

- JVM 测试覆盖日程、休息边界、重启与时钟处理、HMAC 互通、保管码替换规则、通话页面与聊天/桌面的区分。
- Node 测试覆盖离线网页的 SHA-256、HMAC、200 个独立挑战应答及输入校验。
- GitHub Actions 新增一次性 Android 16 模拟器，使用 Android 原生 Instrumentation 检查真实 Keystore、重复打开图标、息屏亮屏、服务断开/重连时的原到期时间与未用长码保持。测试代码只在 `androidTest`，不打入发布 APK。
- 模拟器不登录微信，不能验证用户账号的微信来电，也不等同小米 14 / HyperOS 实机。请用“更多 → 两分钟检测”测试本机图标重开和息屏，再用另一个微信账号测试语音、视频、返回聊天/桌面是否遮住、挂断后是否恢复。

任何检测失败，先关闭每日计划。即使服务失效，计划计时保留也不代表其他应用仍被拦截。

## 升级与隐私

0.2.0、0.3.0 使用同一应用 ID 和固定签名，可覆盖安装；急救长码、Keystore 别名、网页协议保持兼容。0.3.0 的有效计划不因本次界面升级被主动清空。0.2.0 的旧设备所有者策略会恢复，用户可在更多菜单确认移除管理身份，不清空手机。

0.1.0 云端包使用不同临时签名，不能覆盖。需在非学习时段移除旧管理身份并卸载，换装后重新设置急救码。不要为换版恢复出厂设置。

无广告、账号、联网权限和第三方运行依赖。不读取屏幕文字、聊天、联系人、号码或通话记录，不保存前台应用使用历史，不上传任何数据。卸载会移除应用本地数据，妻子持有的备份另行保管。

## 构建与分发

工程位于仓库 `study-lock-android/`，工作流在根目录 `.github/workflows/build.yml`。GitHub Actions 自动构建 APK，并在云端运行生命周期检查，不在用户电脑安装模拟器。

下载最新成功运行的 **StudyLock-Android16-APK**，内含 `study-lock.apk`、`recovery-helper.html`、`SHA256SUMS`。云端生命周期日志单独放在 **StudyLock-Android16-Lifecycle-Evidence**。Actions 产物需登录 GitHub，保留 3 天，本地文件不受期限影响。

发布 APK 为非调试包，沿用 GitHub 加密 Secret 中的固定签名密钥。私钥不提交或打入产物。APK 可交给自愿用户安装，本次没有上架应用商店或获得商店审核。

备用本地构建需 JDK 17、SDK 36 与 build-tools 36.0.0，运行 `./build.ps1`，输出 `dist/学习锁屏-0.4.0.apk`。测试模拟器只在 GitHub 云端启动。

系统机制：[Android 无障碍服务](https://developer.android.com/reference/android/accessibilityservice/AccessibilityService)、[普通悬浮窗](https://developer.android.com/reference/android/view/WindowManager.LayoutParams#TYPE_APPLICATION_OVERLAY)、[UiAutomation 测试标志](https://developer.android.com/reference/android/app/UiAutomation#FLAG_DONT_SUPPRESS_ACCESSIBILITY_SERVICES)。
